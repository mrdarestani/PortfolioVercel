# [my website is mrdarestani.com](https://mrdarestani.com)

This repository contains the source for the portfolio website. Start with the guides below when making updates:

- [Maintenance guide](docs/MAINTENANCE.md): project structure, local setup, checks, CV recovery, and deployment.
- [Portfolio content inventory](docs/PORTFOLIO_CONTENT.md): publication links, awards, Karate details, project ideas, and content follow-ups.

## Quick start

```powershell
npm ci
npm run dev
```

The development server is available at http://localhost:3000.

## Deployment and Maintenance

For deployment, email configuration, content updates, and CV recovery, see the [maintenance guide](docs/MAINTENANCE.md).

`CommandsForGit.txt` and `CommandsForGit-Revised.txt` are retained as historical notes. Their cleanup and forced-upgrade commands are not part of the recommended setup; preserve `package-lock.json` and use `npm ci` for a reproducible install.
